TripNest is a full-featured tour management platform designed to help users plan, book, and experience seamless journeys across the globe. It connects users, vendors, and admins within a structured ecosystem that simplifies tour discovery, booking, and management.


## 🔗 Live URL

https://tripnest-kappa.vercel.app/

## 💡 Key Features

- Users can create account, save their favourite tours, book tours and  leave a review after the tour has been completed
- Vendors can create tours, manage tours, manage booking
- Admins can approve tours, approve users and vendors, manage tours
- Used firebase to handle authentication
- Search, Filter, Layout Shifting feature

## ✨ Custom-Built Features (No External Libraries)

- Custom date picker calender
